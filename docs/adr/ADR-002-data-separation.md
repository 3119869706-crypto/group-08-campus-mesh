# ADR-002：公私数据分离存储

- 状态：已接受
- 日期：2026-11-12
- 决策人：汪星同、陈永学
- 关联 Issue：#2、#12、#15

## 背景

系统同时包含公开内容（校园墙、二课活动）与私密内容（私聊、AI 配置）。如果全部存服务端，隐私风险高；如果全部存本地，公开内容无法跨设备共享。

## 决策

按数据敏感度划分存储边界：

- 私密数据（私聊消息、AI 人设/技能、草稿）只存浏览器 IndexedDB/LocalStorage。
- 公开数据（帖子、评论、活动）存服务端数据库。
- 服务端只保留房间元数据（房间号、匿名 ID、创建时间），24 小时内清理。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 全部服务端 | 实现简单、可跨设备 | 隐私风险、违背项目定位 | 不采用 |
| 全部本地 | 隐私最好 | 无法做公开社区 | 不采用 |
| 公私分离 | 隐私与功能平衡 | 需要明确边界与同步策略 | **采用** |

## 后果

- 正面：答辩时可明确说明“数据库里没有私聊明文”；合规风险低。
- 负面：换设备后私聊记录与 AI 配置不同步；需要提供导出/导入。
- 后续：在设置页提供“导出本地数据 / 清除本地数据”；文档中写明同步限制。
